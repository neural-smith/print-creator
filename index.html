Print Creator

Arrange photographs and create printable PDFs locally in your browser, or install the Linux application.

Open Print Creator in your browser

Signed, automatically updatable Flatpak packages.

Install Print Creator (.flatpakref)

Add repository (.flatpakrepo)

flatpak install --user https://neural-smith.github.io/print-creator/org.neural_smith.PrintCreator.flatpakref

Once installed from this repository, run flatpak update or use your desktop software center for updates.

GitHub's immutable release assets and this signed update repository are independent distribution channels.
